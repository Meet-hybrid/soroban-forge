Commands

soroban-forge newScaffold a contract from a bundled template
soroban-forge buildRelease WASM for wasm32v1-none
soroban-forge testRun a crate's or the workspace's tests
soroban-forge verifyRebuild deterministically and compare SHA-256
soroban-forge invokeCall a function on a deployed contract
soroban-forge eventsStream contract events from a ledger

TypeScript quick start

Copy
import { escrow } from "@soroban-forge/escrow-client"; const client = new escrow.Client({ ...escrow.networks.testnet, rpcUrl: "https://soroban-testnet.stellar.org", }); const id = await client.create_escrow({ buyer, seller, arbiter, token: USDC, amount: 1_500n, timeout: 604_800n, }); await client.deposit({ escrow_id: id.result });
